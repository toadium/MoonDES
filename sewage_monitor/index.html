🧬 AAO脱氮原理

脱氮过程：
1️⃣ 硝化：好氧区硝化菌将NH₄⁺-N → NO₂⁻ → NO₃⁻
2️⃣ 内回流：将硝酸盐氮回流至缺氧区（200-300%）
3️⃣ 反硝化：缺氧区反硝化菌将NO₃⁻ → N₂↑

关键参数：
• 硝化需要SRT ≥ 10天
• 反硝化需要缺氧环境（DO < 0.5 mg/L）
• 碱度消耗：1g NH₄⁺-N硝化消耗7.14g CaCO₃

🧪 AAO除磷原理

生物除磷过程：
1️⃣ 厌氧释磷：聚磷菌在厌氧区释放磷酸盐
2️⃣ 好氧超量吸磷：聚磷菌在好氧区过量吸收磷
3️⃣ 排泥去除：通过排放剩余污泥去除磷

关键条件：
• 厌氧区必须严格厌氧（DO=0，NO₃⁻<0.5mg/L）
• 回流污泥中的硝酸盐会干扰除磷
• SRT宜控制在10-15天

💨 曝气控制策略

曝气系统功能：
• 提供好氧区所需溶解氧
• 混合搅拌，防止污泥沉淀
• 维持MLSS悬浮状态

DO控制策略：
• 好氧区：2-3 mg/L（最经济范围）
• 缺氧区：0.5-1.0 mg/L
• 厌氧区：< 0.5 mg/L

节能措施：
• DO反馈控制曝气量
• 变频率调节风机转速

🔄 污泥回流作用

污泥回流（50-100%）：
• 维持生化池MLSS浓度
• 保证足够微生物量
• 稀释进水污染物浓度

内回流（200-300%）：
• 将好氧区混合液回流至缺氧区
• 提供硝酸盐氮进行反硝化
• 影响脱氮效率的关键参数

回流比计算：
R = Qr/Q = X/(Xr-X)

⚙️ 二沉池设计要点

设计参数：
• 表面负荷：0.8-1.2 m³/(m²·h)
• 固体负荷：≤150 kg/(m²·d)
• 出水堰负荷：≤15 m³/(m·h)

常见问题：
• 泥位过高 → 出水SS超标
• 短流 → 沉淀效果差
• 污泥膨胀 → 泥水分离困难

运行控制：
• 及时排泥，控制泥位
• 调整堰板保持均匀出水

📊 设计计算方法

生化池容积计算：
污泥负荷法：V = Q(S₀-Se)/(X·Ns)
污泥龄法：V = θc·Q·Y·(S₀-Se)/[X·(1+kd·θc)]

曝气量计算：
需氧量 R₀ = Q(S₀-Se)·Y + 4.57Q(N₀-Ne)
标准曝气量 Ws = R₀/(0.277·Cs)

二沉池面积：
表面积 A = Q/q
固体负荷校核 G = Q·X/A ≤ 150
