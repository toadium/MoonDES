# 品牌故事：基于MoonBit的国产化通用离散事件仿真底座及多流体管网仿真业务平台

## 1. 项目名称

### 最终确定名称

**基于MoonBit的国产化通用离散事件仿真底座及多流体管网仿真业务平台**

- 子项目一：「MoonDES」通用离散事件仿真引擎
- 子项目二：「MoonPipe」多流体管网水力仿真业务框架

### 备选名称

| 候选名 | 定位方向 | 推荐理由 |
|--------|---------|---------|
| MoonSim | 面向功能 | 直取 MoonBit Simulation 之意，简洁易记，但社区已有同名极简项目，易混淆 |

| MoonGrid | 面向价值 | 取"月网"之意，体现管网网格，但与未来配电网仿真组件命名冲突 |

## 2. 命名理由

MoonDES 取"MoonBit Discrete Event Simulation"之意，直接体现底层引擎基于 MoonBit 的离散事件仿真能力，DES 是离散事件仿真领域国际通用缩写，便于学术与工程社区识别。

MoonPipe 取"MoonBit Pipeline"之意，体现上层管网业务框架的管道仿真专长，Pipe 一词在流体输送工程中语义明确，覆盖水务、燃气、油气多行业管道场景。

两个子项目各自独立立项、独立版本管控，单向依赖（MoonPipe 依赖 MoonDES），命名上 Moon 前缀统一品牌血脉，DES/Pipe 后缀明确职责边界，整体形成"月之引擎、月之管网"的国产化仿真品牌矩阵。

## 3. 品牌故事

在国家软件国产化替代战略背景下，国内智慧管网平台长期依赖国外 EPANET、SimPy 等仿真软件，存在授权风险、跨端部署难题与动态类型性能瓶颈。每一座城市的供水管网、每一片灌区的输水管道、每一条燃气输送干线，背后都需要精准的水力仿真来支撑调度决策——而支撑这些仿真的核心引擎，却长期握在国外软件手中。

MoonDES+MoonPipe 双子项目从零构建，以国产编译型语言 MoonBit 为根基。MoonDES 以 SimPy 协程调度内核为蓝本，吸收 DESMO-J 实验分层架构，在 MoonBit 静态编译环境下重构通用离散事件仿真底座；MoonPipe 在 MoonDES 之上封装树网/环网双求解器、多流体物性库、业务工况仿真逻辑，一套框架横跨水务、燃气、油气多行业。

一次开发即可编译为 WASI 服务端、WASM 前端、Native 本地程序三种部署形态，彻底摆脱国外软件依赖。我们承诺：完全自主可控的代码根基、一次开发支撑数十类行业仿真的扩展能力、与国内云原生智慧平台完美适配的部署兼容性——为国内管网数字化平台提供属于自己的仿真底座。

## 5. 品牌价值观

1. **自主可控**：全部代码基于 MoonBit 原生开发，无国外仿真引擎闭源许可限制、无跨语言调用兼容性问题，适配国产化软件替代趋势。与 MoonDES 引擎"完全自主可控"的核心功能呼应。

2. **架构解耦**：通用引擎与行业业务框架完全分离，引擎一次开发可支撑数十类行业仿真模型，投入产出比极高。与 MoonPipe"一套框架统一支持树状、环状两大管网拓扑，横跨水务、燃气、油气多行业"的核心功能呼应。

3. **全域兼容**：整套体系可编译为 Linux WASI 后端服务、浏览器 WASM 前端、Windows/macOS 原生程序，完美适配云原生平台、数字孪生前端、本地仿真工作站等各类部署场景。与 MoonDES"序列化跨 WASI/WASM/Native 环境无缝运行"的核心功能呼应。

4. **工程精度**：环状管网与 EPANET 标准算例误差 ≤0.5%，树状管网 10000 节点 10ms 以内完成计算，满足工程设计精度要求。与 MoonPipe 双求解器核心计算能力呼应。

5. **生态协同**：深度复用 MoonBit 现有 mock、dummy_faker、serde、xlsx 等成熟生态库，开发效率高、体系一致性强，以 MoonDES 为底座持续孵化 MoonHeat、MoonHydro、MoonGrid 等系列业务框架。与 MoonDES"标准化插件注册接口"的核心功能呼应。
