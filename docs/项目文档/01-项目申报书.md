# 项目申报书：基于MoonBit的国产化通用离散事件仿真底座及多流体管网仿真业务平台

## 1. 项目概述

本项目依托国产 MoonBit 编译型编程语言，为国内智慧管网数字化平台研发团队打造一套完全自主可控、跨部署环境、面向工业数字化与智慧管网领域的完整仿真技术体系。底层提供通用离散事件仿真运行引擎（MoonDES），上层配套管网行业专用水力计算与场景仿真框架（MoonPipe），形成开箱即用的仿真中间件整体解决方案。

当前国内智慧管网数字化建设高速推进，但行业缺少一套标准化、可嵌入自研平台、支持多流体、双拓扑结构的管网仿真框架。国际主流仿真引擎 SimPy、DESMO-J、OMNeT++ 均无 MoonBit 原生移植版本，且存在动态类型性能差、跨端部署困难、授权约束等问题。本项目以 SimPy 协程调度内核为蓝本，吸收 DESMO-J 模型与实验分层架构，在 MoonBit 环境下从零重构，填补 MoonBit 生态工程仿真核心基础设施空白。

## 2. 项目名称与品牌故事

- **项目名称**：基于MoonBit的国产化通用离散事件仿真底座及多流体管网仿真业务平台
- **子项目一**：MoonDES 通用离散事件仿真引擎
- **子项目二**：MoonPipe 多流体管网水力仿真业务框架

**命名理由**：MoonDES 取"MoonBit Discrete Event Simulation"之意，体现底层引擎基于 MoonBit 的离散事件仿真能力；MoonPipe 取"MoonBit Pipeline"之意，体现上层管网业务框架的管道仿真专长。两个子项目各自独立立项、独立版本管控，单向依赖（MoonPipe 依赖 MoonDES）。

**品牌故事摘要**：在国家软件国产化替代战略背景下，国内智慧管网平台长期依赖国外 EPANET、SimPy 等仿真软件，存在授权风险与跨端部署难题。MoonDES+MoonPipe 双子项目从零构建，以国产编译型语言为根基，一次开发即可编译为 WASI 服务端、WASM 前端、Native 本地程序三种部署形态，彻底摆脱国外软件依赖，为国内管网数字化平台提供自主可控的仿真底座。

## 3. 目标用户与市场分析

### 目标用户画像

- 国内智慧灌区平台、智慧市政水务平台、智慧燃气调度平台、长输油气管道监控平台的后端研发团队
- 工业数字化、数字孪生领域从事时序仿真、调度优化的研发工程师
- MoonBit 生态中需要通用离散事件仿真基础设施的开发者

### 用户痛点

1. 平台开发团队缺少水力算法专业积累，自研求解代码精度参差不齐
2. 大量项目依赖老旧 EPANET/C 库，与新一代云原生、WASM 部署架构不兼容
3. 绝大多数开源代码仅支持自来水单一介质，无法适配燃气、原油等其他流体
4. 缺乏配套测试与标准示例数据集，平台集成调试成本高
5. MoonBit 生态缺少成熟、可商用的通用离散事件仿真引擎

### 市场规模估算

国内智慧水务、智慧燃气、长输油气管道数字化市场规模估算为千亿级（估算值，依据行业公开报告趋势推算，待补充权威数据来源）。其中仿真中间件作为平台核心组件，按国内数十家平台厂商每家年均投入百万级仿真研发成本估算，仿真组件市场年规模约数十亿级（估算值，依据：数十家厂商 × 百万级均价 = 数千万至数亿级年市场）。

| 标准化插件注册接口 | 外部业务模型挂载与生命周期管理 |

### MoonPipe 多流体管网仿真业务框架功能清单

| 功能名 | 说明 |
|--------|------|
| 管网拓扑建模与校验 | 强类型 Node/Pipe/Network 结构，Excel/JSON 导入，连通性检查，树网/环网自动识别 |
| 流体物性与阻力计算 | 多类牛顿流体物性库，海曾-威廉/达西-魏斯巴赫/曼宁阻力公式，局部阻力损失 |

| MoonDES 插件适配 | 封装为仿真插件，时序推进中自动调用管网求解器 |
| 业务工况仿真 | 关阀事故推演、泵站调度、负荷变化、瓶颈识别、压力预警、能耗优化 |
| 示例数据集与测试 | dummy_faker 生成四类标准化数据集，mock 全量算法断言测试 |

### 产品亮点

1. **完全自主可控**：全部代码基于 MoonBit 原生开发，无国外仿真引擎闭源许可限制
2. **架构解耦、扩展性极强**：通用引擎与行业业务框架完全分离，一次开发支撑数十类行业仿真模型
3. **部署全域兼容**：编译为 Linux WASI 后端服务、浏览器 WASM 前端、Windows/macOS 原生程序
4. **性能与安全性双重优势**：静态编译+强类型检查，协程调度轻量化，大规模仿真性能远超 Python 方案
5. **生态协同完善**：深度复用 MoonBit 现有 mock、dummy_faker、serde、xlsx 等成熟生态库

## 5. 技术方案

### 技术栈选型及理由

| 技术 | 用途 | 选型理由 |
|------|------|---------|
| MoonBit | 主开发语言 | 国产编译型语言，静态编译+强类型，原生支持 WASI/WASM/Native 三后端 |
| mock | 单元测试 | MoonBit 官方生态库，提供仿真测试断言能力 |
| serde | 序列化 | MoonBit 官方生态库，支持仿真环境序列化与跨环境运行 |
| dummy_faker | 仿真数据生成 | MoonBit 官方生态库，批量生成标准化示例管网数据集 |
| xlsx | 表格解析 | MoonBit 官方生态库，支持 Excel 管网台账导入 |

### 系统架构简述

整体层级自上而下：

```
各类智慧管网业务平台（智慧水务/灌区/燃气/油气平台）
        ↓
MoonPipe 管网业务仿真框架（插件层，依赖 MoonDES）
        ↓
MoonDES 通用离散事件仿真引擎（底层运行底座，无业务依赖）
        ↓
MoonBit 标准运行时 + 官方生态库（mock、dummy_faker、serde、xlsx）
```

MoonDES 内部采用五层模块化设计：Core 仿真内核层、Process & Coroutine 协程进程调度层、Resource 通用资源管理层、Experiment 仿真实验管理层、Plugin 插件注册与扩展接口层。

MoonPipe 内部采用六层架构：管网拓扑建模与校验层、流体物性与管路阻力计算组件层、双求解器核心计算层、MoonDES 引擎插件适配层、业务工况仿真层、示例数据集与自动化测试层。

### 关键技术难点与对策

1. **协程调度轻量化**：基于 MoonBit 生成器（Generator）实现仿真进程，协程挂起与恢复不占用操作系统线程，支持上万并发进程
2. **环状管网收敛稳定性**：LoopSolver 内置动态松弛因子自适应调节、震荡抑制判断、迭代上限保护机制，极端复杂环路自动切换慢速稳健迭代策略
3. **跨环境序列化**：仿真环境通过 serde 序列化，实现 WASI/WASM/Native 三后端无缝运行
4. **无状态多实例架构**：MoonDES 内核完全无全局可变共享状态，天然支持多实例并行仿真
