# 技术文档：基于MoonBit的国产化通用离散事件仿真底座及多流体管网仿真业务平台

## 1. 概述

本项目依托国产 MoonBit 编译型编程语言，打造完全自主可控、跨部署环境、面向工业数字化与智慧管网领域的完整仿真技术体系。底层提供通用离散事件仿真运行引擎（MoonDES），上层配套管网行业专用水力计算与场景仿真框架（MoonPipe），形成开箱即用的仿真中间件整体解决方案。整体采用"底层通用仿真引擎+上层行业业务框架"双项目独立研发模式，架构科学、边界清晰、单向依赖、扩展性极强。

## 2. 技术栈

| 技术 | 版本 | 用途 |
|------|------|------|
| MoonBit | LTS 稳定版 | 主开发语言，静态编译+强类型，原生支持 WASI/WASM/Native 三后端 |
| mock | 官方生态库 | 单元测试断言，全核心模块测试覆盖率 ≥96% |
| serde | 审方生态库 | 仿真环境序列化，支持跨 WASI/WASM/Native 环境无缝运行 |
| dummy_faker | 审方生态库 | 批量生成标准化示例管网数据集（小规模测试管网、中型灌区树网、城市环状供水管网、环状燃气管网） |
| xlsx | 审方生态库 | Excel 管网台账导入，支持结构化数据解析 |

部署目标：Linux WASI 后端服务、浏览器 WASM 前端、Windows/macOS 原生程序。

## 4. 核心模块设计

### 4.1 MoonDES 通用离散事件仿真引擎（五层模块化）

#### 层级1：Core 仿真内核层

- **职责**：提供全局仿真环境、虚拟仿真时钟、最小堆优先级事件队列、主仿真循环、事件分发机制
- **关键数据结构**（伪代码示意，以 MoonBit 官方语法为准）：

```moonbit
struct SimulationEnv {
  clock : SimClock           // 虚拟仿真时钟
  event_queue : MinHeap      // 最小堆优先级事件队列
  processes : List[Process]  // 仿真进程集合
  until : Double             // 仿真终止时间
}

struct Event {
  time : Double              // 触发时间
  priority : Int             // 优先级
  callback : () -> Unit      // 回调函数
  process_id : ProcessId     // 所属进程
}
```

- **依赖**：MoonBit 标准库
- **设计要点**：最小堆队列保证按仿真时间从小到大有序执行事件；内核完全无全局可变共享状态，天然支持多实例并行仿真

#### 层级2：Process & Coroutine 协程进程调度层

- **职责**：基于 MoonBit 生成器（Generator）实现仿真进程，支持延时等待 timeout、等待指定事件触发、等待资源释放
- **关键接口**（伪代码示意，以 MoonBit 官方语法为准）：

```moonbit
fn process(env : SimulationEnv, behavior : () -> Unit) -> Process
fn timeout(env : SimulationEnv, duration : Double) -> Event
fn wait_event(env : SimulationEnv, event : Event) -> Unit
fn request_resource(env : SimulationEnv, res : Resource) -> Unit
```

- **依赖**：Core 内核层
- **设计要点**：协程挂起与恢复不占用操作系统线程，上万并发进程调度开销极低

#### 层级3：Resource 通用资源管理层

- **职责**：内置独占式资源、共享容量资源、优先级抢占资源三类模型，自动实现资源申请、排队等待、释放、队列排序
- **关键数据结构**（伪代码示意）：

```moonbit
enum ResourceKind {
  Exclusive      // 独占式（如泵站机组）
  Capacity(Int)  // 共享容量（如管网输水限额）
  Preemptive     // 优先级抢占（如调度通道）
}

struct Resource {
  kind : ResourceKind
  capacity : Int
  users : Queue[Process]
  wait_queue : PriorityQueue[Process]
}
```

- **依赖**：Core 内核层、Process 协程层

#### 层级4：Experiment 仿真实验管理层

- **职责**：管控单次或批量仿真实验，包括仿真起止时间、随机数种子管理、多参数遍历批量仿真、运行指标统计、仿真快照保存与断点回滚、仿真报告导出、运行日志采集
- **关键接口**（伪代码示意）：

```moonbit
fn run_experiment(config : ExpConfig) -> ExpResult
fn snapshot(env : SimulationEnv) -> Snapshot
fn rollback(env : SimulationEnv, snap : Snapshot) -> Unit
fn batch_run(configs : List[ExpConfig]) -> List[ExpResult]
```

- **依赖**：Core 内核层、serde（序列化）

#### 层级5：Plugin 插件注册与扩展接口层

- **职责**：定义标准化仿真组件挂载接口，外部业务模型可注册至引擎内部，在指定仿真时间步被引擎自动调用
- **关键接口**（伪代码示意）：

```moonbit
trait SimulationPlugin {
  fn on_step(env : SimulationEnv, current_time : Double) -> Unit
  fn on_event(env : SimulationEnv, event : Event) -> Unit
  fn on_finish(env : SimulationEnv) -> Unit
}

fn register_plugin(env : SimulationEnv, plugin : SimulationPlugin) -> Unit
```

- **依赖**：Core 内核层
- **设计要点**：为 MoonPipe 及未来所有行业仿真框架提供统一接入标准

### 4.2 MoonPipe 多流体管网水力仿真业务框架（六层架构）

#### 层级1：管网拓扑建模与校验层

- **职责**：定义强类型 Node 节点、Pipe 管道、Network 管网整体结构体；支持 Excel 管网台账、JSON 结构化数据导入；自动完成参数合法性校验、管网连通性检查；自动识别树状管网或环状管网
- **关键数据结构**（伪代码示意）：

```moonbit
struct Node {
  id : String
  x : Double
  y : Double
  elevation : Double
  demand : Double        // 节点流量
  pressure : Double?     // 计算结果
}

struct Pipe {
  id : String
  from : Node
  to : Node
  length : Double
  diameter : Double
  roughness : Double     // 粗糙度
  flow : Double?         // 计算结果
}

struct Network {
  nodes : Map[String, Node]
  pipes : List[Pipe]
  topology : TopologyKind  // Tree 或 Loop
}
```

- **依赖**：xlsx（Excel 导入）、serde（JSON 导入）

#### 层级2：流体物性与管路阻力计算组件层

- **职责**：模块化流体管理，内置多类牛顿流体密度、黏度、温度修正参数；集成海曾-威廉、达西-魏斯巴赫、曼宁沿程阻力公式；自动计算阀门、三通、变径局部阻力损失
- **关键数据结构**（伪代码示意）：

```moonbit
struct Fluid {
  name : String
  density : Double       // 密度
  viscosity : Double     // 黏度
  temp_correction : (Double) -> Double
}

enum FrictionFormula {
  HazenWilliams
  DarcyWeisbach
  Manning
}
```

- **内置流体**：市政自来水、灌溉清水、生活污水、雨水
- **可扩展流体**：天然气、原油、成品油及其他牛顿流体

#### 层级3：双求解器核心计算层

- **TreeSolver 树状管网极速递推求解器**：线性自上而下流量分配算法，无迭代、无收敛难题，毫秒级完成上万节点计算
- **LoopSolver 改进 Hardy-Cross 环状管网平差求解器**：动态松弛因子、震荡抑制策略、多级收敛阈值判断，自动迭代校正环路流量
- **关键接口**（伪代码示意）：

```moonbit
fn solve_tree(network : Network, fluid : Fluid) -> SolveResult
fn solve_loop(network : Network, fluid : Fluid, config : LoopConfig) -> SolveResult

struct SolveResult {
  pipe_flows : Map[String, Double]      // 管道流量
  pipe_velocities : Map[String, Double] // 流速
  node_pressures : Map[String, Double]  // 节点压力
  head_losses : Map[String, Double]     // 水头损失
}
```

- **依赖**：层级1、层级2

#### 层级4：MoonDES 引擎插件适配层

- **职责**：将管网求解体系封装为符合 MoonDES 标准的仿真插件，在仿真时序推进过程中引擎自动调用管网求解器完成全网重算
- **关键接口**（伪代码示意）：

```moonbit
struct PipePlugin : SimulationPlugin {
  network : Network
  fluid : Fluid
  solver : SolverKind    // Tree 或 Loop
}
```

- **依赖**：MoonDES Plugin 接口、层级3

#### 层级5：业务工况仿真层

- **职责**：封装上层仿真逻辑，包括管网关阀事故推演、泵站组合调度仿真、逐日逐时用水负荷变化仿真、管网瓶颈自动识别、压力超限预警模拟、管网能耗统计与优化模拟
- **依赖**：层级4

#### 层级6：示例数据集与自动化测试层

- **职责**：基于 dummy_faker 批量生成四类标准化仿真数据集（小规模测试管网、中型灌区树网、城市环状供水管网、环状燃气管网），存放于 examples 目录；基于 mock 对阻力公式、求解器基准算例、极端边界工况做严格结果断言测试
- **依赖**：dummy_faker、mock

## 7. 部署与运行

### 7.1 环境要求

- MoonBit 工具链：LTS 稳定版（moon 命令行工具）
- 目标后端：WASI（Linux 服务端）、WASM（浏览器前端）、Native（Windows/macOS 本地）

### 7.2 启动步骤

```bash
# 安装 MoonBit 工具链（锁定 LTS 版本）
# 获取项目
moon clone moonDES
moon clone moonPipe

# 构建引擎
moon build --target wasm    # WASM 前端
moon build --target wasi    # WASI 服务端
moon build --target native  # 本地原生

# 运行测试
moon test

# 运行示例
moon run examples/moonpipe_demo
```

### 7.3 配置说明

- MoonDES 仿真环境通过 `create_env(until)` 配置仿真终止时间
- MoonPipe 求解器通过 `LoopConfig` 配置松弛因子、收敛阈值、迭代上限
- 流体物性参数通过 `Fluid` 结构体配置，可扩展自定义流体

## 8. 安全与性能

### 8.1 安全措施

- MoonBit 静态编译+强类型检查，编译期杜绝动态语言运行时类型异常
- 仿真内核无全局可变共享状态，避免并发竞争
- 序列化数据通过 serde 类型安全反序列化，防止注入攻击

### 8.2 性能目标

| 指标 | 目标值 |
|------|--------|
| 单仿真环境并发进程数 | 10000+ |
| 调度延迟 | 微秒级 |
| 十万事件仿真速度 | 较 Python SimPy 提升 8 倍以上 |
| 树状管网 10000 节点求解 | 10ms 以内 |
| 环状管网 500 环收敛 | 1 秒内 |
| 环状管网精度（vs EPANET） | 误差 ≤0.5% |
| MoonDES 测试覆盖率 | ≥96% |
| MoonPipe 测试覆盖率 | ≥95% |
